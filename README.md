# OI

一个适合信息学竞赛学习的本地网站。界面参考 DeepSeek 的简洁聊天布局，包含题目讲解、知识创作 Agent、Markdown 知识库三个页面。

## 运行

需要 Node.js 22.13 或以上版本（使用内置 SQLite，无需单独安装数据库）。

```sh
npm install
npm run dev
```

打开 **http://127.0.0.1:5173**。开发前端运行在 5173 端口，本地 API 运行在 3001 端口。

点击右上角「注册」，只需用户名和密码，注册成功后自动登录。用户名为 2–32 个中文、字母、数字、下划线或短横线，密码为 6–128 个字符。已有账号可点击「登录」，登录后右上角显示用户名和退出按钮。

登录后点击输入框的「选择模型」或左下角「模型配置」，填写：

- **接口地址**：服务商的 OpenAI 兼容 Base URL，例如 `https://your-provider.com/v1`。根据服务商实际要求填写前缀；程序会追加 `/chat/completions`。
- **模型 ID**：在「配置中的模型」手动添加服务商提供的准确 ID，或从 API 获取列表后勾选加入。
- **API Key**：你的接口密钥。

也可以复制 `.env.example` 为 `.env`，通过 `AI_BASE_URL`、`AI_MODEL`、`AI_API_KEY` 配置服务器默认模型。每个账号的设置优先于环境变量；未配置密钥时仍可使用共享知识库。

模型配置支持新增、编辑和删除多套配置。每套配置可保存最多 200 个模型，共用接口地址和 API Key，并可指定默认模型。可以手动添加模型 ID，也可以在填写接口地址和密钥后点击「从 API 获取模型列表」，搜索、勾选并点击「加入所选模型」，最后保存配置。获取列表使用服务商的 `GET /models` 接口（追加在 Base URL 后）；不支持该接口的服务商仍可手动添加。编辑已保存配置时，密钥留空可直接使用服务端保存的密钥获取列表。

输入框旁的下拉框按配置分组，可直接切换组内模型，选择按账号保存，刷新或重新登录后恢复。已有单模型设置自动兼容；环境变量配置显示为只读的「服务器默认」。修改接口地址时需要重新填写密钥，密钥不会返回浏览器。生成期间禁用快速切换，当前回复使用发起请求时选择的模型。

下拉框旁的设置按钮打开配置管理。保存配置不会切换当前聊天模型；首次添加配置时自动选用，当前模型被移除时回退至该配置的默认模型。编辑其他配置或修改默认模型不会影响当前选择。配置列表分别标记正在编辑的配置和「当前使用」的配置；也可点击「使用默认模型」主动切换。关闭弹窗或切换编辑对象时，未保存的修改会提示确认。

## 功能

### 题目讲解

支持流式回复、连续对话、停止生成、Markdown、表格、代码高亮和复制。可以附加文本或代码文件，也可以引用知识库中的笔记。对话按账号自动保存在 SQLite 中，支持搜索、重新打开和删除；AI 回复可以一键另存为共享笔记。回复、思考过程和工具结果都会保存，停止生成或关闭浏览器时也会保留已生成的内容。

同一对话同时只允许一个生成请求；其他页面尝试生成或覆盖保存会收到冲突提示。保存使用版本校验，旧页面无法覆盖新记录。点击历史对话可重新读取最新内容；生成结束后以服务器保存的记录为准。

不注入 system / developer 提示词。发送到模型的是用户和 AI 的实际聊天记录。文本附件以明文内容发送；图片可在输入框中通过 `Ctrl + V` 粘贴，也可通过附件按钮或拖放添加，支持 PNG、JPEG、WebP、GIF，单张最大 2 MB，一次最多 4 个附件。图片可预览、移除或单独发送，并随对话保存在个人数据库中。图片以多模态消息发送，需要配置支持图片输入的模型。不支持代码执行。

输入框下方的「思考强度」滑块提供默认、低、中、高四档。默认档不传递额外参数，其余档位分别传递 `reasoning_effort: "low" / "medium" / "high"`；可点击重置图标恢复默认。该偏好按账号保存，重新登录后恢复。

对话、知识库阅读和编辑预览均支持 LaTeX 数学公式：行内使用 `$O(\log n)$`，独立公式使用以下写法，也支持标记为 `math` 的代码块。公式字体随网站打包，无需访问外部 CDN；普通代码中的美元符号保持原样。

```markdown
$$
\sum_{i=1}^{n} i = \frac{n(n+1)}{2}
$$
```

### 云端运行、历史与重试

对话栏中的「使用云端」适用于普通聊天和 Agent。开启后，服务器确认接收任务并独立执行模型请求和文件工具，网页断网、刷新或关闭不会取消任务。重新打开历史对话可恢复查看进度，也可停止生成。云端使用部署本服务的服务器网络；本地运行时仍使用本机网络，需要远程云端请先将服务部署到持续在线的服务器。服务器关机或重启会中断任务，已保存内容保留，重启后标记为中断，不会自动重放文件操作。

用户消息和 AI 消息支持编辑、删除，生成期间禁止修改。编辑只修改该条消息，已有后续回复保留，不会自动重新生成。修改和删除按账号保存，并校验对话版本。

历史记录无自动过期或条数淘汰，手动删除除外。侧栏每次加载 30 条摘要，可加载更早对话；搜索查询服务器上的全部对话标题，也支持分页。长对话先渲染最近 40 条消息，再按需展开。历史浏览与模型上下文窗口分开：模型请求仍使用最近 60 条对话。

每套模型配置支持最大重试次数 0–10，默认 2，0 表示禁用。模型请求和获取模型列表遇到临时网络错误或 HTTP 408、429、500、502、503、504 时退避重试；已开始消费的流不会自动重放，避免重复回复或重复文件操作。只读网页 API 请求也会适当重试，登录注册和写入操作不会盲目重试。API Key 输入使用带视觉遮罩的普通文本字段，禁用自动补全，并向常见密码管理器声明忽略。

Agent 工具目录只返回路径和标题，支持分页；文件默认每次最多读取 12,000 字符，可通过 offset/limit 继续读取。工具历史中的大段正文会压缩，已执行的写入参数不再完整回传模型。工具结果仍保存用于界面查看，优先使用 edit_file 做局部修改可进一步减少 token。

### 知识创作 Agent

使用同一套可配置接口，为模型提供以下函数工具，**不添加系统提示词**：

- `list_files`：查看知识库。
- `read_file`：读取 Markdown。
- `write_file`：创建或完整更新 Markdown，自动创建目录。
- `edit_file`：精确替换文件中唯一匹配的一段文字。

工具操作会显示在对话里。文件操作限定在 `data/notes/`，禁止路径穿越、符号链接和非 Markdown 文件。Agent 没有命令执行与文件删除权限。每条用户消息最多进行 8 轮模型调用；需要所接模型支持流式函数调用。

可以直接告诉 Agent：「读取基础算法/二分查找.md，补充一道例题并保存。」

### 共享 Markdown 知识库

支持文件夹浏览、搜索、阅读目录、源码编辑、新建、重命名或移动、删除、批量导入与导出。`Ctrl + S` 保存，未保存的编辑在离开时会提示。附带 6 篇基础算法、数据结构、动态规划、图论和数学示例笔记，可自由修改。

所有登录用户共用同一个知识库，可以查看、创建、编辑和删除同一份笔记及文件夹；Agent 同样操作此共享知识库。笔记保留为真实 Markdown 文件。对话和模型配置仍属于各自账号。多人同时修改同一篇笔记时，以最后一次保存的内容为准，暂不提供版本合并。

## 数据与存储

```text
data/
  notes/             # 所有用户共享的真实 Markdown 文件
  workspace.sqlite   # 账号、登录会话、个人对话、消息和设置
  workspace.sqlite-wal / workspace.sqlite-shm  # 数据库运行时文件
```

密码使用独立随机盐和 scrypt 哈希保存。登录使用 HttpOnly、SameSite Cookie，会话有效期为 30 天，退出时立即失效；登录会话在服务重启后仍有效。所有知识库、对话、设置和 AI 接口都要求登录，接口按当前账号读取和保存个人数据。登录与注册接口限制重复尝试，请求来源必须与网站一致。

模型密钥保存在 SQLite 或 `.env` 中，不返回给前端，也不会进入 Git。API 请求从服务端发送至你配置的服务商；引用的笔记和附件也会作为对话内容发给该服务商。停止服务后备份整个 `data/` 即可保留笔记、账号、历史和设置。可以通过 `OI_DATA_DIR` 指定另一个数据目录。

所有新注册账号均从空白个人空间开始，不导入旧账号的对话或配置，也不读取旧 `chats.json` 和 `settings.json`。共享知识库独立于个人数据，所有登录用户仍可共同使用。

服务默认只监听 `127.0.0.1`。同一服务上的多个账号共享知识库，使用各自的对话和配置。

## 生产运行与检查

服务器部署、Cloudflare Tunnel 域名配置、更新和备份步骤见 [deploy/README.md](deploy/README.md)。

```sh
npm run build
npm start
```

生产界面和 API 由同一个服务提供：**http://127.0.0.1:3001**。

```sh
npm test          # API、真实文件操作、边界、Agent 和流式协议测试
npm run test:ui   # 桌面与移动浏览器测试，自动启动独立测试服务
npm run test:production # 生产构建浏览器检查，需要先执行 npm run build
```

浏览器测试默认使用已安装的 Google Chrome。后端和浏览器测试使用临时数据库，不修改实际账号、对话或配置。聊天测试使用模拟的 AI 返回，后端工具测试使用模拟的兼容接口；接入真实服务商后，实际响应取决于模型能力与接口配置。无需真实密钥即可运行这些检查。

## 技术栈

React 19、TypeScript、Vite、Express、SQLite、React Markdown、Lucide。界面适配手机与桌面，支持键盘操作与减少动态效果的系统偏好。
